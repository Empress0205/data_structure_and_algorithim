# Data Structures and Algorithms in Python

Group coursework exercises solving introductory algorithm problems in Python.

| File | Problem |
| --- | --- |
| `0-hello.py` | Greet a user by name |
| `1-smallest_int.py` | Find the smallest integer in a list |
| `2-search_int.py` | Find the first index of a value in a list |
| `3-print_triangle.py` | Print a right triangle of a given height |
| `4-factorize.py` | Break an integer into its prime factors |
| `5-sum_even.py` | Sum the even numbers in a list |
| `6-char_frequency.py` | Count character frequencies in a string |
| `7-is_prime.py` | Check whether a number is prime |
| `8-two_indices.py` | Find two indices whose values add up to a target |
| `9-int_to_roman.py` | Convert an integer to a Roman numeral |

All files are in `000-programming_in_python/` and run with `python <file>.py`.
